# Security Policy

## Reporting a vulnerability

Please report suspected OmniFox security vulnerabilities privately to:

**security@omnifox.app**

Do not open a public GitHub issue for vulnerabilities or include exploit
details, credentials, personal data, or diagnostic archives in a public post.

Include only what is needed to investigate:

- affected OmniFox version and operating system
- affected component or installer profile
- clear reproduction steps
- expected and observed behavior
- potential impact
- relevant logs or screenshots after removing sensitive information
- a safe way to contact you

Do not access other people's data, degrade services, perform denial-of-service
testing, use social engineering, or test against accounts and systems you do
not own or have permission to use.

We will acknowledge a valid report as soon as practical, investigate it
privately, and coordinate remediation and disclosure when appropriate. Please
allow reasonable time for a fix before publishing details.

## Supported releases

Security support begins with the first public OmniFox release. The current
stable release receives priority. Older releases may require updating before a
fix can be applied. Release notes will identify any additional supported
versions or exceptions.

## Installer authenticity

Official OmniFox releases are distributed only through this repository,
<https://omnifox.app/download>, and OmniFox-controlled update/CDN domains.
Verify the publisher signature and published SHA-256 checksum before installing
a downloaded package.

Report suspicious, modified, or impersonating installers to
`report@omnifox.app`.
